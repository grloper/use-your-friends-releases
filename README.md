# Use Your Friends

**1–4 player co-op horror.** Your friends are the tools. The goo is recruiting.

A co-op horror game set in **ARGON-9**, a drowned research facility seven sectors deep. You and your friends are jelly-blob researchers. The black goo takes the dead — and sends them back hunting as **the Hollowed**.

## The game

- **7 sectors, one facility:** Breach Point → Pump Hall → Flooded Archives → Valve Maze → Machine Deck → Choir Loft → Brood Cavern. One continuous claustrophobic complex. No levels, no timers, no races.
- **Friends are tools:** Morph into **Plank**, **Boing**, **Ball**, **Sticky**, or **Balloon**. Every puzzle needs 2+ living players using each other's bodies. Solo completion is a design bug.
- **The Hollowed:** When the goo takes a player, they don't die — they come back wrong and hunt their former crew.
- **Spooky + funny:** Comedy from panic, physics, and helpless geometry. Never grimdark.
- **Sound is everything:** Every monster is heard before it's seen.

## Monsters

- **Barnacle Choir** — records and replays voice chat
- **Pressure Leech** — mimics pressure pads
- **Tension Eel** — mimics conduit/bridge geometry
- **Depth Inspector** — sonar drone hunting transformed players
- **The Hollowed** — your dead friend, back wrong

## Install

1. Download **UseYourFriends-Setup-v0.18.0.exe** from the [latest release](https://github.com/grloper/use-your-friends-releases/releases/latest) and run it. No admin rights needed.
2. The playtest build is unsigned, so Windows may say *"Windows protected your PC"*: click **More info → Run anyway**.

Prefer no installer? Grab the portable `.zip`, extract, and run `UseYourFriends.exe`.
