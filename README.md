# Use Your Friends: downloads

A 1–4 player couch co-op physics party game where you turn into tools for your friends (plank, boing, ball), and then let them fall.

## Install (Windows 10/11, 64-bit)
1. Download **UseYourFriends-Setup-vX.Y.Z.exe** from the [latest release](https://github.com/grloper/use-your-friends-releases/releases/latest).
2. Run it. No admin rights are needed; it installs to your user folder.
   The build is unsigned, so SmartScreen may say "Windows protected your PC". Click **More info → Run anyway**.
3. Start **Use Your Friends** from the Start menu or the desktop.

**Updates are automatic:** when a new version is out, the main menu shows an **UPDATE!** button (or press U / Y on a gamepad).
The game downloads the installer, checks its SHA-256, installs it and restarts. You can also use *Settings → UPDATES*.

Prefer no installer? Each release also has a portable .zip (no auto-update).
